# SPHERIC 2028 — conference website

Static site for the 21st SPHERIC World Conference, hosted at Monash University Clayton campus (11–15 December 2028).

**Live URL (once Pages is enabled):** https://spheric2028.github.io

## Edit locally

1. Change content in `index.html` (dates, copy, contact).
2. Adjust colours and type in `css/styles.css` (`:root` variables).
3. Preview without a server:

```bash
open -a Safari index.html
```

## Branding

Drop the conference logo into `assets/brand/` — see [assets/brand/README.md](assets/brand/README.md).

## GitHub Pages

In the repository settings: **Pages → Deploy from a branch → `main` / `/ (root)`**.
